# learn-rust

My notes and small programs while learning Rust.

## Run

```bash
cargo run                           # main program
cargo run --example 01_ownership    # ownership
cargo run --example 02_borrowing    # references & borrowing
cargo run --example 03_structs_enums
```

## Contents

| Example | Topic |
|---|---|
| `examples/01_ownership.rs` | Ownership, move, clone, Copy |
| `examples/02_borrowing.rs` | `&T` and `&mut T` |
| `examples/03_structs_enums.rs` | Structs, enums, `match` |
