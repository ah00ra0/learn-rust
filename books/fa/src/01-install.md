# نصب Rust روی ویندوز، مک و لینوکس

ابزار رسمی نصب و مدیریت نسخه‌های Rust، برنامه‌ای به نام **rustup** است. با نصب آن، این‌ها نصب می‌شوند:

- `rustc`: کامپایلر Rust
- `cargo`: ابزار ساخت پروژه و مدیریت پکیج
- `rustup`: برای به‌روزرسانی و تغییر نسخه

## لینوکس و مک

ترمینال را باز کنید و این دستور را اجرا کنید:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

گزینه‌ی پیش‌فرض (`1`) را انتخاب کنید. پس از پایان، ترمینال را ببندید و دوباره باز کنید.

برای کامپایل کردن، به یک لینکر (linker) هم نیاز است:

- **مک**: دستور `xcode-select --install`
- **اوبونتو و دبیان**: دستور `sudo apt install build-essential`

## ویندوز

1. به سایت رسمی [rust-lang.org/tools/install](https://www.rust-lang.org/tools/install) بروید.
2. فایل `rustup-init.exe` را دانلود و اجرا کنید.
3. اگر از شما خواست **Visual Studio C++ Build Tools** را نصب کنید، موافقت کنید. بدون آن، لینک کردن برنامه کار نمی‌کند.
4. گزینه‌ی پیش‌فرض را بزنید و صبر کنید.

> **نکته:** اگر دسترسی به سایت‌ها محدود است، می‌توانید از میرورهای rustup استفاده کنید. برای این کار، متغیرهای `RUSTUP_DIST_SERVER` و `RUSTUP_UPDATE_ROOT` را به آدرس میرور مورد نظر تنظیم کنید.

## بررسی نصب

در ترمینال بزنید:

```bash
rustc --version
cargo --version
```

باید خروجی‌ای شبیه این ببینید (شماره نسخه ممکن است فرق کند):

```text
rustc 1.90.0 (xxxxxxxxx 2025-xx-xx)
cargo 1.90.0 (xxxxxxxxx 2025-xx-xx)
```

## به‌روزرسانی و حذف

```bash
rustup update        # به‌روزرسانی به آخرین نسخه
rustup self uninstall  # حذف کامل Rust
```

## ویرایشگر کد

هر ویرایشگری کار می‌کند، اما این پیشنهادها تجربه بهتری می‌دهند:

- **VS Code** به‌همراه افزونه‌ی **rust-analyzer**: محبوب‌ترین گزینه است. تکمیل خودکار، نمایش نوع متغیرها و نمایش خطا هنگام تایپ دارد.
- **RustRover**: محیط توسعه اختصاصی Rust از JetBrains.
- **Neovim / Helix / Zed**: با پشتیبانی rust-analyzer.

## ابزارهای جانبی مهم

این دو ابزار همراه rustup نصب می‌شوند و در طول کتاب استفاده می‌کنیم:

```bash
cargo fmt      # فرمت خودکار کد
cargo clippy   # پیشنهادهای بهبود کد
```

## مستندات آفلاین

با دستور زیر کتاب رسمی Rust در مرورگرتان باز می‌شود، حتی بدون اینترنت:

```bash
rustup doc --book
```
