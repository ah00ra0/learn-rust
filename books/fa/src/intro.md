# مقدمه: Rust چیست و چرا باید یادش گرفت؟

به **آموزش جامع Rust (راست) به زبان فارسی** خوش آمدید. این کتاب رایگان و متن‌باز است و هدفش این است که فقط با خواندن آن، از صفر تا سطح یک برنامه‌نویس Rust مسلط پیش بروید.

## Rust چیست؟

**Rust** یک زبان برنامه‌نویسی سیستمی، سریع و ایمن است. این زبان در سال ۲۰۰۶ به‌عنوان پروژه شخصی گریدون هور (Graydon Hoare) شروع شد، بعدها موزیلا از آن حمایت کرد و نسخه ۱.۰ آن در سال ۲۰۱۵ منتشر شد. امروز Rust توسط بنیاد Rust (Rust Foundation) و جامعه‌ای بزرگ از توسعه‌دهندگان نگهداری می‌شود.

سه ویژگی اصلی Rust این‌هاست:

1. **سرعت**: Rust به کد ماشین کامپایل می‌شود و سرعتی در حد C و C++ دارد. Garbage Collector ندارد.
2. **ایمنی حافظه**: بیشتر خطاهای رایج حافظه (مثل دسترسی به حافظه آزادشده، data race و null pointer) در زمان **کامپایل** گرفته می‌شوند، نه زمان اجرا.
3. **ابزار عالی**: ابزارهایی مثل `cargo` (مدیریت پروژه و پکیج)، `rustfmt` (فرمت کد) و `clippy` (راهنمای کد بهتر) همراه خود زبان می‌آیند.

## Rust را کجا می‌بینیم؟

Rust در حوزه‌های زیر کاربرد زیادی دارد:

- **سیستم‌عامل و زیرساخت**: بخش‌هایی از هسته لینوکس، اندروید و ویندوز با Rust نوشته می‌شوند.
- **وب‌سرور و بک‌اند**: با فریم‌ورک‌هایی مثل Axum و Actix.
- **ابزارهای خط فرمان**: مثل `ripgrep`، `bat` و `fd`.
- **WebAssembly**: اجرای کد سریع در مرورگر.
- **بازی‌سازی و گرافیک**: مثل موتور Bevy.
- **سیستم‌های نهفته (Embedded)** و **بلاکچین**.

## چرا یادگیری Rust ارزش دارد؟

- سال‌های متوالی در نظرسنجی Stack Overflow پرطرفدارترین زبان بین توسعه‌دهندگان شناخته شده است.
- یادگیری آن شما را مجبور می‌کند درباره حافظه، مالکیت داده‌ها و همزمانی عمیق‌تر فکر کنید. این دانش در هر زبان دیگری هم به کارتان می‌آید.
- بازار کار Rust در حال رشد است و شرکت‌های زیادی به دنبال برنامه‌نویس Rust هستند.

## Rust سخت است؟

صادقانه بگوییم: **شیب یادگیری Rust از بیشتر زبان‌ها تندتر است.** دلیلش مفاهیمی مثل Ownership و Lifetime است که در زبان‌های دیگر وجود ندارد. اما خبر خوب این است:

- کامپایلر Rust پیغام‌های خطای بسیار دقیق و راهگشا می‌دهد.
- وقتی این مفاهیم جا بیفتند، کد نوشتن در Rust لذت‌بخش و مطمئن می‌شود.
- این کتاب مفاهیم را قدم‌به‌قدم و با مثال توضیح می‌دهد.

## این کتاب برای چه کسی است؟

- کسی که تازه برنامه‌نویسی را شروع کرده و Rust را به‌عنوان اولین زبانش انتخاب کرده است.
- برنامه‌نویسانی که با پایتون، جاوااسکریپت، جاوا، C++ یا Go کار کرده‌اند و می‌خواهند Rust یاد بگیرند.

پیش‌نیاز خاصی لازم نیست. فقط اگر با ترمینال (خط فرمان) آشنا باشید، کارتان راحت‌تر است.

## چطور از این کتاب استفاده کنیم؟

- فصل‌ها را **به ترتیب** بخوانید. هر فصل روی فصل قبل بنا شده است.
- روی دکمه ▶ کنار مثال‌ها بزنید تا کد در Rust Playground اجرا شود.
- **حتماً خودتان کد را تایپ کنید** و تغییر بدهید. فقط خواندن کافی نیست.
- آخر هر فصل تمرین هست. قبل از رفتن به فصل بعد حلش کنید.
- مثال‌هایی که با علامت ✗ در عنوانشان مشخص شده‌اند، **عمداً خطا دارند** تا ببینید کامپایلر چه می‌گوید.
