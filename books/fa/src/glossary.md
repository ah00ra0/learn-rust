# واژه‌نامه فارسی - انگلیسی

این فهرست اصطلاحات پرکاربرد Rust و معادل‌های فارسی آن‌هاست. در جامعه‌ی برنامه‌نویسی فارسی‌زبان معمولاً خود اصطلاح انگلیسی به کار می‌رود، بنابراین در کتاب هم بیشتر همان را استفاده کرده‌ایم.

| انگلیسی | فارسی | توضیح کوتاه |
|---|---|---|
| Ownership | مالکیت | هر مقدار دقیقاً یک مالک دارد |
| Borrowing | قرض‌گیری | استفاده از مقدار بدون گرفتن مالکیت |
| Reference | مرجع / ارجاع | `&T` یا `&mut T` |
| Lifetime | طول عمر | بازه‌ی معتبر بودن یک reference |
| Move | انتقال | منتقل شدن مالکیت |
| Copy | کپی | کپی ارزان و ضمنی |
| Clone | همانندسازی | کپی صریح و عمیق |
| Drop | آزادسازی | پاک شدن مقدار در پایان scope |
| Scope | حوزه | بازه‌ای از کد که متغیر معتبر است |
| Stack | پشته | حافظه‌ی سریع با اندازه‌ی ثابت |
| Heap | هیپ / انباره | حافظه‌ی پویا |
| Slice | برش | reference به بخشی از مجموعه |
| Struct | ساختار | نوع داده‌ی مرکب با فیلدهای نام‌دار |
| Enum | شمارشی | نوعی با چند حالت ممکن |
| Pattern | الگو | ساختار تطبیق در `match` و `let` |
| Trait | ویژگی / رابط | مجموعه‌ای از رفتارها |
| Generic | عمومی / جنریک | کد مستقل از نوع |
| Trait Bound | قید trait | شرط روی نوع generic |
| Trait Object | شیء trait | `dyn Trait` |
| Closure | بستار | تابع بی‌نام با capture محیط |
| Iterator | پیمایشگر | شیء پیمایش عناصر |
| Module | ماژول | واحد سازمان‌دهی کد |
| Crate | کریت / بسته‌ی کامپایل | واحد کامپایل (کتابخانه یا اجرایی) |
| Package | پکیج | یک یا چند crate با Cargo.toml |
| Macro | ماکرو | کدی که کد تولید می‌کند |
| Smart Pointer | اشاره‌گر هوشمند | `Box`, `Rc`, `Arc` و ... |
| Interior Mutability | تغییرپذیری درونی | تغییر داده از طریق `&T` (مثل `RefCell`) |
| Concurrency | همزمانی | چند کار در حال پیشرفت |
| Parallelism | موازی‌سازی | چند کار هم‌زمان روی چند هسته |
| Thread | رشته‌ی اجرا / نخ | واحد اجرای سیستم‌عامل |
| Channel | کانال | انتقال پیام بین thread ها |
| Mutex | قفل انحصاری | یک thread در هر لحظه |
| Data Race | رقابت داده | دسترسی همزمان ناامن به حافظه |
| Deadlock | بن‌بست | منتظر ماندن دائمی threadها برای هم |
| Async | ناهمگام | برنامه‌نویسی غیرمسدودکننده |
| Future | آینده‌مقدار | مقداری که بعداً آماده می‌شود |
| Runtime | محیط اجرا | زمان‌بند Future ها (مثل Tokio) |
| Unsafe | ناامن | بلوکی که بررسی‌های اضافی را به عهده‌ی برنامه‌نویس می‌گذارد |
| Panic | وحشت / توقف اضطراری | پایان ناگهانی برنامه |
| Compiler | کامپایلر | مترجم کد به کد ماشین |
| Borrow Checker | بررسی‌گر قرض | بخشی از کامپایلر که قوانین ownership را می‌سنجد |
| Monomorphization | تک‌شکلی‌سازی | تولید نسخه‌ی مجزا برای هر نوع generic |
| Zero-cost Abstraction | انتزاع بدون هزینه | انتزاع بدون سربار اجرا |
| Shadowing | سایه‌اندازی | تعریف مجدد متغیر با همان نام |
| Dereference | ارجاع‌زدایی | دسترسی به مقدار از طریق reference با `*` |
| Dangling Reference | مرجع معلق | reference به حافظه‌ی آزادشده |
| Static Dispatch | ارسال ایستا | تعیین تابع در زمان کامپایل |
| Dynamic Dispatch | ارسال پویا | تعیین تابع در زمان اجرا |
| Edition | ویرایش | نسخه‌ی سازگاری زبان (2015، 2018، 2021، 2024) |

> **پیشنهاد:** اگر پیشنهادی برای معادل بهتر دارید یا اصطلاحی جا مانده، [یک Issue باز کنید](https://github.com/ah00ra0/learn-rust/issues).
