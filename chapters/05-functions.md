# توابع و کامنت‌ها

## تعریف تابع

توابع با کلمه‌ی `fn` تعریف می‌شوند. نام توابع در Rust به سبک **snake_case** است (حروف کوچک و `_` بین کلمات):

```rust
fn main() {
    println!("شروع");
    another_function();
}

fn another_function() {
    println!("تابع دیگر");
}
```

ترتیب تعریف توابع مهم نیست؛ می‌توانید `another_function` را قبل یا بعد از `main` بنویسید.

## پارامترها

نوع هر پارامتر **حتماً** باید نوشته شود:

```rust
fn main() {
    print_labeled(5, 'm');
}

fn print_labeled(value: i32, unit: char) {
    println!("مقدار: {value}{unit}");
}
```

## Statement و Expression

این تمایز در Rust بسیار مهم است:

- **Statement** (دستور): کاری انجام می‌دهد و **مقداری برنمی‌گرداند**. مثل `let y = 6;`
- **Expression** (عبارت): **مقداری تولید می‌کند**. مثل `5 + 6` یا بلوک `{ ... }`

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1      // بدون سمی‌کالن: این یک expression است و مقدار بلوک می‌شود
    };
    println!("y = {y}"); // 4
}
```

اگر به انتهای `x + 1` سمی‌کالن اضافه کنید، آن را به statement تبدیل کرده‌اید و بلوک `()` برمی‌گرداند.

## مقدار بازگشتی

نوع بازگشتی بعد از `->` نوشته می‌شود. مقدار بازگشتی همان آخرین expression بدنه است (بدون `;`):

```rust
fn five() -> i32 {
    5
}

fn plus_one(x: i32) -> i32 {
    x + 1
}

fn main() {
    println!("{} {}", five(), plus_one(5));
}
```

برای خروج زودهنگام از `return` استفاده می‌شود:

```rust
fn abs_value(x: i32) -> i32 {
    if x < 0 {
        return -x;
    }
    x
}

fn main() {
    println!("{}", abs_value(-7));
}
```

خطای رایج مبتدی‌ها: گذاشتن `;` در انتها

```rust,compile_fail
fn plus_one(x: i32) -> i32 {
    x + 1; // ✗ خطا: با سمی‌کالن، تابع () برمی‌گرداند نه i32
}
```

## بازگرداندن چند مقدار

با tuple می‌توان چند مقدار برگرداند:

```rust
fn min_max(a: i32, b: i32) -> (i32, i32) {
    if a < b { (a, b) } else { (b, a) }
}

fn main() {
    let (small, big) = min_max(9, 3);
    println!("{small} {big}");
}
```

## کامنت‌ها

```rust
// این یک کامنت تک‌خطی است

/* این یک
   کامنت چندخطی است */

fn main() {
    let x = 5; // کامنت انتهای خط
    println!("{x}");
}
```

### کامنت مستندات (Doc Comment)

با `///` برای مستندسازی توابع و انواع. این متن‌ها با `cargo doc` به مستندات HTML تبدیل می‌شوند و از Markdown پشتیبانی می‌کنند:

```rust
/// دو عدد را با هم جمع می‌کند.
///
/// # مثال
///
/// ```
/// let result = add(2, 3);
/// assert_eq!(result, 5);
/// ```
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    println!("{}", add(2, 3));
}
```

نکته جالب: مثال‌های داخل `///` هنگام `cargo test` هم تست می‌شوند و مستندات همیشه به‌روز می‌مانند.

برای مستندسازی خود ماژول یا crate از `//!` در ابتدای فایل استفاده می‌شود.

## تمرین

1. تابعی بنویسید که دمای سانتی‌گراد را به فارنهایت تبدیل کند (`F = C × 9/5 + 32`).
2. تابعی بنویسید که یک عدد را بگیرد و مربع و مکعب آن را به‌صورت tuple برگرداند.
3. تابعی بنویسید که n-امین عدد فیبوناچی را حساب کند (فعلاً با `if` و `return`).
4. برای یکی از توابعتان doc comment همراه با مثال بنویسید.
