# Hello World و آشنایی با Cargo

## اولین برنامه

یک پوشه بسازید و فایلی به نام `main.rs` در آن ایجاد کنید:

```rust
fn main() {
    println!("سلام دنیا!");
}
```

با دستور `rustc` کامپایل و اجرا کنید:

```bash
rustc main.rs
./main          # در ویندوز: main.exe
```

خروجی:

```text
سلام دنیا!
```

### این کد چه می‌کند؟

- `fn main()` تعریف یک تابع به نام `main` است. اجرای هر برنامه Rust از این تابع شروع می‌شود.
- `{ ... }` بدنه‌ی تابع را مشخص می‌کند.
- `println!` یک **macro** است، نه تابع معمولی. علامت `!` این را نشان می‌دهد. این macro متن را چاپ می‌کند و به خط بعد می‌رود.
- هر دستور با `;` تمام می‌شود.
- تورفتگی (indent) در Rust با ۴ فاصله انجام می‌شود.

## Cargo: ابزار اصلی Rust

در عمل تقریباً هیچ‌کس مستقیم از `rustc` استفاده نمی‌کند. **Cargo** کارهای زیر را انجام می‌دهد:

- ساخت پروژه
- کامپایل
- دانلود و مدیریت کتابخانه‌ها (که در Rust به آن‌ها **crate** می‌گویند)
- اجرای تست‌ها
- ساخت مستندات

### ساخت پروژه جدید

```bash
cargo new hello_rust
cd hello_rust
```

ساختار پروژه:

```text
hello_rust/
├── Cargo.toml
└── src/
    └── main.rs
```

فایل `Cargo.toml` اطلاعات پروژه را نگه می‌دارد:

```toml
[package]
name = "hello_rust"
version = "0.1.0"
edition = "2024"

[dependencies]
```

- بخش `[package]` نام، نسخه و edition را مشخص می‌کند.
- بخش `[dependencies]` جایی است که کتابخانه‌های مورد نیاز را می‌نویسید.

### دستورات مهم Cargo

| دستور | کاربرد |
|---|---|
| `cargo build` | کامپایل پروژه (حالت debug) |
| `cargo run` | کامپایل و اجرا |
| `cargo check` | فقط بررسی خطا، بدون ساخت فایل اجرایی (خیلی سریع‌تر) |
| `cargo build --release` | کامپایل بهینه‌شده برای انتشار |
| `cargo test` | اجرای تست‌ها |
| `cargo fmt` | فرمت کد |
| `cargo clippy` | پیشنهاد بهبود کد |
| `cargo doc --open` | ساخت و باز کردن مستندات |

> **نکته:** در حین نوشتن کد از `cargo check` زیاد استفاده کنید. چون فایل اجرایی نمی‌سازد، بسیار سریع‌تر از `cargo build` است.

### حالت debug و release

- `cargo build` فایل را در `target/debug/` می‌سازد. زمان کامپایل کم است ولی برنامه کندتر اجرا می‌شود.
- `cargo build --release` فایل را در `target/release/` می‌سازد. کامپایل طولانی‌تر است ولی برنامه بسیار سریع‌تر اجرا می‌شود.

برای اندازه‌گیری سرعت و انتشار نهایی، همیشه از `--release` استفاده کنید.

### اضافه کردن کتابخانه

مثلاً برای استفاده از کتابخانه تولید عدد تصادفی `rand`:

```bash
cargo add rand
```

این دستور خط مربوطه را در بخش `[dependencies]` می‌نویسد. کتابخانه‌ها از سایت [crates.io](https://crates.io) دانلود می‌شوند.

### فایل Cargo.lock

Cargo پس از اولین build فایل `Cargo.lock` را می‌سازد و نسخه دقیق همه‌ی وابستگی‌ها را در آن ثبت می‌کند تا build شما همیشه تکرارپذیر باشد. این فایل را دستی ویرایش نکنید.

## تمرین

1. با `cargo new` یک پروژه به نام `my_first` بسازید و آن را اجرا کنید.
2. متن خروجی را به نام خودتان تغییر دهید.
3. با `println!` سه خط مختلف چاپ کنید.
4. دستور `cargo build --release` را اجرا کنید و محل فایل اجرایی را پیدا کنید.
