# متغیرها، تغییرپذیری و ثابت‌ها

## تعریف متغیر با let

در Rust متغیر با کلمه‌ی `let` تعریف می‌شود:

```rust
fn main() {
    let x = 5;
    println!("مقدار x برابر است با {x}");
}
```

داخل `{}` در `println!` می‌توانید مستقیم نام متغیر را بنویسید (این قابلیت format string است).

برای عبارت‌های پیچیده‌تر از `{}` خالی و آرگومان استفاده کنید:

```rust
fn main() {
    let a = 3;
    let b = 4;
    println!("جمع {} و {} برابر است با {}", a, b, a + b);
}
```

## متغیرها به‌طور پیش‌فرض تغییرناپذیرند

این یکی از مهم‌ترین تفاوت‌های Rust با زبان‌های دیگر است. اگر مقدار یک متغیر را بخواهید عوض کنید:

```rust,compile_fail
fn main() {
    let x = 5;
    x = 6; // ✗ خطا: نمی‌توان به متغیر تغییرناپذیر دوباره مقدار داد
    println!("{x}");
}
```

کامپایلر خطای `cannot assign twice to immutable variable` می‌دهد.

چرا؟ چون وقتی بدانید مقداری تغییر نمی‌کند، فهمیدن و اشکال‌زدایی کد ساده‌تر است و بخش زیادی از باگ‌ها از بین می‌روند.

## تغییرپذیری با mut

اگر واقعاً نیاز به تغییر دارید، کلمه‌ی `mut` (مخفف mutable) را اضافه کنید:

```rust
fn main() {
    let mut x = 5;
    println!("x = {x}");
    x = 6;
    println!("x = {x}");
}
```

خروجی:

```text
x = 5
x = 6
```

> **قاعده کلی:** فقط وقتی `mut` بگذارید که واقعاً لازم است. کامپایلر هم اگر `mut` غیرضروری بگذارید هشدار می‌دهد.

## ثابت‌ها (const)

ثابت‌ها همیشه تغییرناپذیرند و تفاوت‌هایی با `let` دارند:

- با `const` تعریف می‌شوند و **نوع آن‌ها باید نوشته شود**.
- نمی‌توان `mut` به آن‌ها داد.
- مقدارشان باید در **زمان کامپایل** مشخص باشد.
- می‌توانند در هر scope از جمله سطح بیرونی فایل تعریف شوند.
- نام‌گذاری آن‌ها با حروف بزرگ و `_` است.

```rust
const MAX_POINTS: u32 = 100_000;
const SECONDS_IN_HOUR: u32 = 60 * 60;

fn main() {
    println!("{MAX_POINTS} {SECONDS_IN_HOUR}");
}
```

> **نکته:** در اعداد بزرگ می‌توانید برای خوانایی از `_` استفاده کنید: `1_000_000`.

## Shadowing (سایه‌اندازی)

می‌توانید متغیری با **همان نام** دوباره با `let` تعریف کنید. متغیر جدید متغیر قبلی را "سایه‌اندازی" می‌کند:

```rust
fn main() {
    let x = 5;
    let x = x + 1;

    {
        let x = x * 2;
        println!("x داخل بلوک: {x}"); // 12
    }

    println!("x بیرون بلوک: {x}"); // 6
}
```

### تفاوت shadowing با mut

۱. در shadowing یک متغیر **کاملاً جدید** ساخته می‌شود، بنابراین می‌توانید **نوع** را هم عوض کنید:

```rust
fn main() {
    let spaces = "   ";         // نوع: &str
    let spaces = spaces.len();  // نوع: usize
    println!("{spaces}");
}
```

۲. اگر همین کار را با `mut` انجام دهید، خطای نوع می‌گیرید:

```rust,compile_fail
fn main() {
    let mut spaces = "   ";
    spaces = spaces.len(); // ✗ خطا: نوع‌ها یکسان نیستند
}
```

۳. بعد از shadowing، متغیر جدید هم همچنان تغییرناپذیر است مگر خودتان `mut` بگذارید.

## Scope (حوزه)

متغیر از جایی که تعریف شده تا انتهای بلوک `{ }` که در آن قرار دارد معتبر است:

```rust
fn main() {
    {
        let inner = 10;
        println!("{inner}");
    } // اینجا inner از بین می‌رود

    // println!("{inner}"); // ✗ خطا: inner دیگر وجود ندارد
}
```

این مفهوم در فصل Ownership نقش کلیدی دارد.

## تمرین

1. متغیری با `let` تعریف کنید و سعی کنید مقدارش را عوض کنید. خطا را بخوانید.
2. آن را با `mut` درست کنید.
3. یک `const` برای عدد پی (`3.14159`) تعریف کنید و مساحت دایره‌ای با شعاع ۵ را چاپ کنید.
4. با shadowing، یک متغیر رشته‌ای را به عدد تبدیل کنید (راهنمایی: `"42".parse::<i32>().unwrap()`).
